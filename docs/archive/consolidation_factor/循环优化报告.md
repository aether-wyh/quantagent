# 盘整后连续放量长K线：循环优化报告

运行日期：2026-08-12

## 规则与资料

- 股票范围：按信号日和买入日检查沪深300历史成分资格。
- 训练资料：2015-01-05至2021-12-31。
- 开发检查：2022、2023、2024三段。
- 2025没有运行，也没有反馈给循环。
- 买入费0.03%，卖出费0.08%，每边价格偏差0.025%。
- 信号在第二个放量日D收盘确认，下一实际交易日开盘买入。
- 基准信号：D-31至D-2共30根有效日K线；29个收盘收益率的样本标准差不高于1.5%；D-1和D成交量均不低于同一30日均量的2倍；D满足 `high-low > 2*abs(close-open)`；不分涨跌和上下影线；持有5个完整交易日，第6日开盘卖出。

本次日线资料和此前5477只全A股事件检查不是同一股票范围，收益数字不能直接互相比较。

## 结论

五个版本都没有通过完整要求，核心问题是2022年始终不稳定。1.0%版本样本明显减少且2023大幅变差；3日版本提高了夏普中位数并降低回撤，但2022仍亏损；收阳和2.5倍放量都只改善个别年份。

当前只能保留第1轮作为后续研究基准，不能把它称为可用策略，也不应运行2025。下一次若继续，优先研究为何2022和其他年份方向相反，或用新的、未看过时期做一次独立检查；不建议继续细调相近阈值。

第一轮曾因程序判断错误被复制到 `best_experiments`；该副本已移到本目录的 `rejected_loop_archives`，避免被误认为通过版本。原始运行记录没有删除。
