# AI 量化策略项目交付说明

整理日期：2026-08-25  
主项目：`QuantaAgents`  
辅助项目：`新建文件夹(1)`

## 1. 交付结论

这是一套把量化想法逐步变成策略代码、检查策略规则、分段回测并保存研究过程的项目。目前最有价值的成果是研究程序、检查程序、回测程序和完整的尝试记录；现有研究结果还不能直接视为可投入真实资金的策略。

最近一次完整研究停在确认期：选中的 `candidate_004` 在确认期 3 段中 0 段通过，因此最终时期没有运行。这是有意停止，不是遗漏。

## 2. 项目包含什么

### 2.1 `QuantaAgents`

主项目负责：

- 读取一句策略想法、实验 YAML 或研报文件；
- 整理策略含义和所需资料；
- 生成第一版策略及后续候选；
- 检查代码能否运行、是否误用未来资料、目标持仓是否合理；
- 运行日线、分钟事件或 Level 2 事件研究；
- 按时间分段检查收益、回撤、费用和推迟执行后的表现；
- 保存每一次候选、修改内容、检查结果和回测结果；
- 通过网页查看运行进度、实验文件和日志；
- 在规则冻结后，只有得到明确许可才运行一次最终时期。

### 2.2 `新建文件夹(1)`

这是较早的两套沪深 300 日线策略及独立重跑脚本，包含：

- `rolling`：双重趋势确认和多因子轮换；
- `indicator`：按 ADX 区分市场状态，再使用不同的选股规则；
- 2024—2025 年的实际代码重跑结果；
- 每日资金、成交、目标持仓、参考收益和中文回测报告。

这部分依赖 `QuantaAgents` 中的本地日线回测代码。

## 3. 主要运行顺序

旧版运行方式：

```text
实验设置
  → 研究策略假设
  → 生成策略代码
  → 程序检查
  → 开发期分段回测
  → 未通过：只改一个主要问题后再试
  → 通过：冻结候选
  → 得到明确许可后：运行一次最终时期
```

V2 运行方式：

```text
一句想法或研报
  → 整理原意和缺少的信息
  → 在看收益前列出几种可能解释
  → 写出忠实于原意的第一版
  → 每次只检查一个研究问题
  → 研究期选择候选
  → 确认期检查选中的候选
  → 确认期通过后才允许进入最终时期
```

## 4. 设计思路

### 4.1 把研究、确认和最终检查分开

研究期可以反复使用，确认期只检查研究期选出的版本，最终时期最多运行一次。最终时期结果不会再返回前面继续修改规则，减少看过结果后反复调整造成的假象。

### 4.2 研究判断和程序计算分开

模型负责整理想法、提出原因和写候选代码。能否运行、日期是否正确、是否使用未来资料、是否满足费用和分段要求，由固定程序判断。模型不能修改回测数字，也不能自行宣布通过。

### 4.3 每次正式回测只回答一个问题

每一轮只允许一个主要变化，并保存变化前后的规则和成绩。失败版本不会继续叠加修改，而是回到最近一次采用的版本。

### 4.4 不只看总收益

开发检查同时看：

- 多个时间段是否都能工作；
- 最差一段的表现；
- 是否每段都胜过持有现金；
- 费用加倍后是否还能工作；
- 晚一个交易日执行后是否还能工作；
- 交易次数是否足够；
- 多次尝试后，较高夏普是否可能只是偶然。

### 4.5 尽量还原真实可交易时间

日线信号在收盘后确定，原则上在下一个实际交易日执行；指数成分资格按当时日期检查；A 股研究注明 T+1 限制。分钟事件若不具备符合 T+1 的退出写法，只能描述价格现象，不能写成真实交易收益。

### 4.6 保存全部尝试

每个候选都会保存策略代码、规则变化、研究说明、程序检查、分段成绩、资金曲线和失败原因。中断后可以从已有记录恢复，旧记录不被覆盖。

## 6. 已做过的主要尝试

### 6.1 日线因子和轮换策略

先后尝试过 ADX 市场状态判断、沪深 300 多因子、ATR、TEMA、Amihud、时间重心、价格时滞、不同持股数量和现金比例等。现有记录中没有一个版本达到预先设定的完整要求。

因子日历三因子初版为 2/3 段通过，但最差夏普为 -0.338；后续多个版本仍没有达到夏普 1.50 的目标，也没有运行 2025 年最终时期。ADX 轮换两版的夏普中位数约为 -1.47，均失败。

### 6.2 盘整后连续两日放量与长 K 线

全 A 股事件检查发现：波动率不高于 1.5% 时，5 日逐事件扣费平均收益为 +0.31%，但中位数为 -0.25%，扣费后盈利比例为 47.36%；把同一天的信号等权合并后，平均收益变为 -0.16%。少数集中出现信号的上涨日抬高了普通平均值。

长影线相对只看连续放量有约 +0.20% 的 5 日筛选价值，但不足以单独作为买入依据。

循环研究又比较了基准、波动率 1.0%、持有 3 日、信号日收阳和放量 2.5 倍五个版本。五个版本全部未通过，主要问题是 2022 年始终不稳定。

### 6.3 盘整放量 V2

最近选中的 `candidate_004` 在原“30 日盘整、连续两日放量、两日小实体”基础上，只保留信号日流通市值不高于全市场中位数的股票。

它在较早研究期相对原版有所改善：

- 年化收益中位数：-2.78% → +8.52%；
- 夏普中位数：-0.187 → +0.472；
- 最差回撤：53.43% → 40.06%；
- 仍只有 2/4 段通过，最差夏普为 -4.111。

尝试过的其他方向包括收盘位置、盘整波动率、删除第一日小实体、持有 2 日、上沿突破，以及几种市场走弱过滤。最新记录把这些候选记为拒绝；其中有些记录没有完整开发成绩，不能把“被记录为拒绝”写成“已经完成正式回测”。

### 6.4 分钟规律放量

`candidate_011` 在 2024 年开发资料中有 8,919 个事件，观察 20 分钟后扣 0.16% 费用的平均结果为 +0.0519%。2025 年最终时期重试后为 -0.0132%，最终检查失败；2025 已经被看过，不能再作为新的未知时期。

`candidate_012` 在 011 上增加“触发时价格明显低于实时五日均线”的条件，在 2024 年有 1,664 个事件，扣费后平均为 +0.2644%，双倍费用后平均为 +0.1044%。但它仍是 20 分钟价格现象，不符合 A 股当日买入后当日退出的限制，不能直接写成可交易收益。

### 6.5 较早两套策略的重跑

`新建文件夹(1)/backtest_outputs/回测报告.md` 的结果为：

- `rolling`：2024—2025 年扣费后累计亏损 11.63%；不扣费用时盈利 26.64%，说明频繁交易造成的费用影响很大；
- `indicator`：扣费后累计盈利 41.84%，略高于同期历史沪深 300 成分股每日等权参考的 37.23%，但最大回撤更大、夏普略低；
- 这只是一个固定时期的重跑结果，还不能证明未来有效。

## 8. 当前已知问题

- 16 项失败；

失败主要集中在：

- 一处中文提示和对应检查出现乱码；

这些问题没有在本次打包中修改，避免把交付任务变成代码改造任务。

另外还有以下限制：

- `README.md` 中有两处配置名和代码实际读取的名称不一致；以 `.env.example` 为准；
- PDF 和 Word 输入所需的 `pypdf`、`python-docx` 没有写进 `pyproject.toml`；
- Parquet 读取通常需要 `pyarrow`，目前只在开发用的附加依赖中；
- 多个脚本带有本机 D 盘或 F 盘资料位置，换电脑时需要重新指定；
- 分钟事件资料缺少真实订单、持仓、可成交数量、停牌及涨跌停状态；
- 项目目前没有单独的开源许可文件，不应在未确认授权方式前公开再发布。

## 9. 安装与运行

要求 Python 3.10 或更高版本。

进入 `QuantaAgents` 后安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[web,research,dev]"
```

如需 vn.py 方式：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[vnpy]"
```

复制安全配置示例：

```powershell
Copy-Item .env.example .env
```

然后填写自己的服务地址、密钥和资料位置。不要把填写后的 `.env` 公开。

运行旧版批量实验：

```powershell
.\.venv\Scripts\python.exe -m quanta_agents.main
```

运行 V2 示例：

```powershell
.\.venv\Scripts\python.exe scripts\run_research_loop_v2.py experiments\consolidation_volume_box_research_v2.yaml
```

打开网页查看工具：

```powershell
.\.venv\Scripts\python.exe -m quanta_agents.webapp
```

默认访问 `http://127.0.0.1:8000`。

重跑较早两套策略：

```powershell
..\新建文件夹(1)\run_folder_backtest.py
```

实际运行时需要补成：

```powershell
.\.venv\Scripts\python.exe "..\新建文件夹(1)\run_folder_backtest.py" --parquet "D:\你的日线资料\*.parquet" --membership "D:\你的历史成分文件\csi300.txt"
```

## 10. 外部资料要求

交付包不包含原始行情和个人数据库。运行前需要按所选方式准备：

- 日线 Parquet，至少含日期、股票代码、开盘、最高、最低、收盘和成交量；
- 沪深 300 等指数的历史成分文件；
- 或 `market_data.db` 与 `vnpy_bar.sqlite3`；
- 分钟研究所需的事件 Parquet；
- Level 2 研究所需的外部逐笔成交和十档行情。
