# 两套策略回测报告

## 结论

- `rolling` 表现不合格：扣除费用后累计亏损 11.63%。不扣费用时可以盈利 26.64%，但频繁交易把收益全部吃掉。
- `indicator` 扣除费用后累计盈利 41.84%，略高于同期历史沪深300成分股每日等权参考的 37.23%；不过它的最大回撤更大，夏普略低。
- 两套策略都存在大量交易。`rolling` 的费用影响尤其严重。

## 回测设置

- 前期资料：2020-01-01 至 2023-12-31。
- 检验时期：2024-01-02 至 2025-12-31，共 485 个交易日。
- 行情：项目配置的本地前复权日线 Parquet。
- 股票范围：沪深300期间成员并集；实际成交时检查当日历史成分资格。
- 初始资金：100 万元。
- 买入费用：成交额的 0.03%。
- 卖出费用：成交额的 0.08%。
- 成交价偏差：买卖每边 0.10%。
- 权重日期：DataFrame 的 D 日信号在下一个交易日开盘执行。

## 额外检查

| 检查 | rolling | indicator |
|---|---:|---:|
| 次日开盘执行，完全不扣费用 | +26.64% | +82.97% |
| 错误地提前到信号当日开盘执行，仍扣费用 | -32.04% | +32.30% |

旧报告曾把 D 日信号错误地提前到 D 日开盘执行。现已按项目规则修正为下一个交易日开盘执行，并覆盖每日资金、成交记录和汇总结果。

## 需要特别注意

- 两个旧策略代码要求后复权表，但各自 JSON 指定的正式回测来源是前复权表。本次按 JSON 使用前复权数据，并只在运行内存中使用旧代码要求的表名。
- 项目读取的是“检验时期内出现过的全部沪深300成员”。原策略算大盘和选股分数时没有逐日排除非当日成员，只在成交时才检查。`rolling` 平均有 8.37% 的目标股票权重落在非当日成员上，`indicator` 为 9.24%，因此仍不能完全排除未来名单带来的影响。
- 本地行情截至 2025-12-31，无法计算文件中写到 2026-07-23 的时期。
- 本次保留了原代码行为，包括 `rolling` 不完整的内部回撤计算，以及 `indicator` 的旧买入价、自然日持有和未实现的部分风险规则。

完整机器结果见 `summary.json`，每日资金和成交记录见同目录的 CSV 文件。
